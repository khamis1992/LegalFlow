# LawTec ERP - نظام إدارة مكاتب المحاماة

نظام SaaS شامل لإدارة مكاتب المحاماة مبني بتقنية React

## المميزات الرئيسية

- 🏢 إدارة شاملة للقضايا والعملاء
- 👥 6 أنواع من المستخدمين (Super Admin، صاحب المكتب، المدير، المحامي، الموظف، العميل)
- 💼 نظام محاسبي متكامل
- 📄 إدارة المستندات والعقود
- 👔 نظام الموارد البشرية
- 📊 تقارير وتحليلات متقدمة
- 💳 نظام اشتراكات متعدد المستويات

## التقنيات المستخدمة

- React 19.1.0
- Vite 6.3.5
- React Router 7.6.1
- Tailwind CSS 4.1.7
- Radix UI Components
- React Hook Form + Zod
- Recharts
- Date-fns

## التثبيت والتشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل المشروع
npm run dev

# بناء المشروع
npm run build
```

## البنية الهيكلية

```
src/
├── components/
│   ├── super-admin/     # لوحة Super Admin
│   ├── owner/           # لوحة صاحب المكتب
│   ├── manager/         # لوحة المدير
│   ├── lawyer/          # لوحة المحامي
│   ├── employee/        # لوحة الموظف
│   ├── client/          # بوابة العميل
│   ├── shared/          # مكونات مشتركة
│   ├── layout/          # مكونات التخطيط
│   └── ui/              # مكونات واجهة المستخدم
├── context/             # إدارة الحالة
├── hooks/               # React Hooks المخصصة
├── utils/               # دوال مساعدة
└── routes/              # ملفات التوجيه
```
